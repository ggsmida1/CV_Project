## 4.2 系统框架设计（30分）

### 模板设计部分（12分）

#### 设计思路（4分）

模板设计模块负责建立检测基准。用户加载一张标准模板图片后，通过鼠标拖拽在图片上标记一个或多个感兴趣区域（ROI），系统自动提取每个 ROI 的子图像作为后续残缺检测的参照。配置以 JSON 文件保存，模板图像以 base64 编码嵌入 JSON，保证配置自包含，不依赖原始图片路径。

#### 功能架构图（4分）

```mermaid
graph TD
    subgraph 模板设计模块
        A[加载模板图片] --> B[鼠标拖拽选择ROI]
        B --> C[添加ROI到列表]
        C --> D[在模板上绘制ROI框]
        D --> E{继续添加?}
        E -->|是| B
        E -->|否| F[保存配置文件]
        F --> G[JSON + base64编码]
    end
```

#### 模块功能说明（4分）

| 功能 | 说明 |
|------|------|
| 加载模板图片 | 读取 PNG/JPG/BMP/TIF 格式图片，校验合法性，清空旧 ROI |
| ROI 选择 | 鼠标拖拽模式：按下记录起点 → 移动实时绘制矩形框 → 释放时确认区域 |
| ROI 管理 | 添加、删除、列表浏览，选中高亮显示（绿色边框） |
| 配置保存 | 将模板信息与所有 ROI 参数（位置、子图像）序列化为独立 JSON 文件 |
| 配置加载 | 从 JSON 反序列化还原模板 + ROI，支持跨设备迁移 |

### 检测模块部分（18分）

#### 设计思路（6分）

检测模块接收待测图片后依次执行四步流水线：**倾斜矫正 → 模板匹配定位 → ROI 精对齐 → 残缺判定**。倾斜矫正通过边缘检测 + 霍夫变换计算图片旋转角度并进行仿射变换补偿。模板匹配使用归一化互相关（NCC）找到模板在待测图中的位置。对每个预定义的 ROI，在匹配结果周边做局部精匹配以提高对齐精度。最后将对齐后的测试区域与模板区域做 NCC 比对，分数低于阈值则判为残缺。

#### 功能架构图（6分）

```mermaid
graph TD
    subgraph 检测流水线
        A[加载待测图片] --> B[倾斜矫正]
        B --> C[模板匹配定位]
        C --> D[遍历每个ROI]
        D --> E[ROI精对齐]
        E --> F[NCC残缺检测]
        F --> G[标注结果 + 记录]
    end
```

#### 模块功能说明（6分）

| 功能 | 说明 |
|------|------|
| 单张检测 | 加载单张图片，执行完整流水线，更新界面 |
| 批量检测 | 多张图片逐张执行检测流水线 |
| 倾斜矫正 | Canny + HoughLinesP → 中位数角度 → warpAffine 旋转补偿 |
| 模板匹配 | NCC 归一化互相关全图搜索，返回最佳匹配点 |
| ROI 对齐 | 在匹配点周边搜索窗口内做局部 NCC 精匹配 |
| 残缺检测 | ROI 区域 NCC 比对，defectScore = 1 - NCC 分数，阈值 0.15 |
| 结果摘要 | 检测页面底部显示每条 ROI 的状态和残缺百分比 |

## 4.4 系统设计总结（5分）

本系统以 Qt + OpenCV 为技术栈，采用**模板匹配 + NCC 差异比对**方法实现了对印刷字符的自动化残缺检测。系统分为模板设计、字符检测、检测结果三大模块，提供了从模板配置到批量检测、结果导出的完整工作流。

**技术要点：**

- **倾斜矫正**：Canny + HoughLinesP + 中位数角度 + warpAffine，对 ±45° 以内的倾斜具有良好矫正能力
- **ROI 精匹配**：在粗定位基础上附加局部 NCC 搜索，提升了对小偏移/旋转的容忍度
- **残缺判定**：NCC 归一化互相关对光照和对比度变化不敏感，0.15 的阈值在实际测试中对明显残缺和微缺陷有较好区分
- **配置自包含**：ROI 子图以 base64 嵌入 JSON，配置文件可脱离原始图片独立迁移

**可改进方向：**

- 引入深度学习（CNN/分类器）替代 NCC 阈值判定，提升对复杂缺陷的识别率
- 支持非矩形 ROI（多边形/自由形状）
- 添加实时视频流检测模式
